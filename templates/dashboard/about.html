About this project

BloodConnect is a Community Blood Donor and Emergency Request System built as a college mini project. It helps a local community keep a list of willing blood donors and manage emergency blood requests in one place.

What it does

  • Secure registration, login, and role-based dashboards.
  • Donor profiles with blood group, city, availability, and contact-sharing consent.
  • Public donor search with preliminary blood-group compatibility filtering.
  • Emergency blood requests with a tracked lifecycle: Open → Matched → Partially Fulfilled → Fulfilled, plus Cancelled and Expired.
  • A status history (audit trail) for every request change.
  • Administrator dashboard with live statistics and abuse-report review.

What it is not

  • It is not an emergency dispatch service — in an emergency, call local emergency services or go to the nearest hospital.
  • It does not confirm medical eligibility, clinical compatibility, or real blood availability. Every match is a potential lead that healthcare professionals must verify.
  • It does not store medical records, and it never shares a donor's phone number unless the donor explicitly consented and the viewer is logged in.

Technology

Python Django (server-rendered templates), HTML5/CSS3/vanilla JavaScript on the front end, and SQLite for storage — fully runnable on a standard Windows laptop with no database installation.

All demonstration data in this project is synthetic.
